# Staged round: LRU cache

This round has several stages.
Each stage adds a production requirement to the code you already wrote, the way a real interviewer adds follow-ups.

- The current stage's requirements are in the panel on the right.
- **Run tests** runs that stage's hidden tests, plus the tests of every stage you already passed, against `lru_cache.py`.
- The next stage unlocks when they all pass. You can also skip a stage; that is recorded.
- The interviewer reads your code and test results. Talk to them in the panel: think out loud, ask clarifying questions, explain your choices.

Use the terminal for anything else, such as a scratch script or your own tests.
